Assignment name  : common

Expected files   : common.c
Allowed functions: write

--------------------------------------------------------------------------------

Write a program that takes several strings as arguments and displays, without
doubles, the characters that appear in all the strings.

The characters must be displayed in the order they appear in the first
argument.

The display will be followed by a \n.

If the number of arguments is less than 2, the program displays a \n.

Examples:

$> ./a.out "abcde" "bcdf" "xbcy" | cat -e
bc$

$> ./a.out "hello" "world" "hold" | cat -e
lo$

$> ./a.out "abcdef" "xyz" | cat -e
$

$> ./a.out "aaa" "aabb" "abc" | cat -e
a$

$> ./a.out "abcdef" "bcdef" "cdef" "def" | cat -e
def$

$> ./a.out | cat -e
$
